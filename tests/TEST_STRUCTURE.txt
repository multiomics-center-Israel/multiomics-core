HOW TO RUN TESTS
================================================================================

From RStudio / R Console:
─────────────────────────────────────────────────────────────────────────────
  # All tests
  testthat::test_file("tests/testthat/test-metadata_profile.R")

  # With runner script
  source("tests/run_profiler_tests.R")

  # Specific category
  testthat::test_file("tests/testthat/test-metadata_profile.R",
                      filter = "batch")

  # Interactive debugging
  source("R/core/08_metadata_profile.R")
  meta <- make_simple_meta(20)
  effects <- list(color = "Treatment", samples = "SampleID")
  prof <- assess_metadata_complexity(meta, effects)
  print_metadata_profile(prof)


================================================================================
WHAT GETS TESTED
================================================================================

INPUT:
  ┌─────────────────┐
  │ Sample Metadata │  (data.frame with rownames = sample IDs)
  └─────────────────┘
          +
  ┌─────────────────┐
  │ Effects Config  │  (list: color, shape, samples)
  └─────────────────┘
          +
  ┌─────────────────┐
  │ Thresholds      │  (optional: max samples, max levels, etc.)
  └─────────────────┘

          ↓

  assess_metadata_complexity()

          ↓

OUTPUT:
  ┌──────────────────────────────────────┐
  │ Profile List                          │
  │  ├─ n_samples, n_vars                │
  │  ├─ primary_col, n_groups_primary    │
  │  ├─ is_simple_2group                 │ ← TESTED
  │  ├─ has_batch_like, batch_cols       │ ← TESTED
  │  ├─ complexity_label                 │ ← TESTED
  │  ├─ suggested_mappings (color/shape) │ ← TESTED
  │  ├─ annotation_cols (for heatmaps)   │ ← TESTED
  │  ├─ plots (gating decisions)         │ ← TESTED
  │  └─ thresholds (stored config)       │ ← TESTED
  └──────────────────────────────────────┘


================================================================================
TEST ASSERTIONS USED
================================================================================

Structure:
  • expect_type(prof, "list")
  • expect_true("plots" %in% names(prof))

Complexity:
  • expect_equal(prof$complexity_label, "simple")
  • expect_true(prof$is_simple_2group)
  • expect_equal(prof$n_groups_primary, 2)

Batch Detection:
  • expect_true(prof$has_batch_like)
  • expect_true("Batch" %in% prof$batch_cols)

Annotations:
  • expect_true("Condition" %in% prof$annotation_cols)
  • expect_equal(prof$annotation_cols[1], "PrimaryColumn")
  • expect_lte(length(prof$annotation_cols), 5)

Plot Gating:
  • expect_true(prof$plots$pca_1v2)
  • expect_false(prof$plots$expr_heatmap)

Thresholds:
  • expect_equal(prof$thresholds$max_samples_for_heatmaps, 120)
