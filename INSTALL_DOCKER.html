Docker Install — Windows

multiomics-core

Three steps. No R version, no RTools, no Bioconductor headache.

1
Install Docker Desktop
~10 min · one-time

Download and run the installer:

👉 https://www.docker.com/products/docker-desktop

  • Keep all defaults. Let it enable WSL2 if prompted.
  • Reboot Windows when the installer asks.
  • After reboot, open Docker Desktop from the Start menu.
  • Wait until the system tray icon (bottom-right) shows the green "Engine running" bubble — about 60 seconds.
If your Windows is older or your machine doesn't support virtualization, Docker won't install. In that case, switch to the native install guide instead.
2
Start the wizard
~5 min · first time

In File Explorer, open the multiomics-core folder (where this HTML file lives).

Double-click the file:

🐳
docker-run.bat
Pulls the prebuilt image (~5 min, only first time) and starts the wizard.

A black Command Prompt window opens and shows progress. Wait until you see:

Starting wizard at http://localhost:8080

Your browser should open automatically. If it doesn't, click here: http://localhost:8080

If the pull fails (no internet, or the image hasn't been published yet for this branch), the script falls back to building the image locally — that takes ~30 min. You'll only ever pay that cost once.
3
Try an example dataset
~30-60 sec

In the wizard header, click one of:

  • ★ Load Example (Metabolomics) — 150 metabolites × 6 samples
  • ★ Load Example (Lipidomics) — 120 lipid species × 8 samples
  • ★ Load Example (Proteomics) — 80 proteins × 6 samples

All fields auto-fill. Scroll to the bottom and click Run Pipeline.

When the run finishes, the HTML report opens automatically. A copy is saved in the outputs folder next to this guide.

4
Using your own data (later)
whenever

Copy your input files into the user_data folder that docker-run.bat auto-created next to itself.

In the wizard, reference them with paths like:

data/user/my_run/metab_intensities.csv

Reports land in the outputs folder (on Windows, not inside the container).

5
Stop, restart, update
when needed

Stop: press Ctrl+C in the Command Prompt that's running the wizard, or just close the window.

Restart: double-click docker-run.bat again — starts in ~10 sec the second time.

Get the latest version: docker-run.bat pulls the most recent image every launch. To skip the pull (offline use), set DOCKER_OFFLINE=1 before launching.

Done.

The same docker-run.bat works on every machine with Docker Desktop installed. To update to a newer version, just rerun docker-run.bat — it pulls the latest image automatically.
