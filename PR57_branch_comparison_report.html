REVERTED Security Fixes

1. Dockerfile: Non-root User

Dor added a non-root user to the Docker container, following security best practices:

# Dor's addition (REVERTED in PR #57): +RUN useradd -m -u 1000 appuser && chown -R appuser:appuser /app +USER appuser

Without this, the container runs as root, which is a security risk in production environments and violates Docker security best practices.

2. system() → system2() Hardening

In 04b_integration_mofa.R, Dor replaced system() calls with system2() to prevent shell injection. PR #57 reverts this.

# Vulnerable (main/PR #57): system(paste("python3", script_path, ...)) # Secure (Dor_branch): system2("python3", args = c(script_path, ...), stdout = TRUE, stderr = TRUE)

3. .gitignore for Local Settings

Dor added .claude/settings.local.json to .gitignore to prevent personal tool settings from being committed. PR #57 reverts this.
