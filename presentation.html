What data does it handle?

P Proteomics

Mass spectrometry data (DIA-NN output). Identifies and quantifies thousands of proteins across your samples.


Input: Protein intensity matrix + sample metadata

M Metabolomics

LC-MS metabolite data (Compound Discoverer). Measures small molecules and metabolic changes.


Input: Compound Discoverer export + metadata

R RNA-seq

Gene expression from sequencing. Measures which genes are turned on or off and by how much.


Input: Count matrix (or tximport) + metadata

L Lipidomics

Lipid species quantification. Maps lipid composition changes across conditions.

Step 1–2: Loading & Preprocessing

P Proteomics

  • Filter low-confidence proteins (must appear in enough replicates)
  • Normalize across samples to make them comparable
  • Impute missing values — MS data always has gaps where a protein wasn't detected
  • Uses multiple imputation (10 rounds) so no single guess drives the results

R RNA-seq

  • Filter lowly expressed genes (need detectable expression in your conditions)
  • Normalize for library size differences (TMM or VST methods)
  • Annotate genes with readable names (Ensembl IDs → gene symbols)
  • Supports non-model organisms via Trinotate
Why impute? In mass-spec proteomics, a protein not detected doesn't mean it's absent — it might just be below the detection limit. Multiple imputation draws plausible values from the low-abundance range and repeats the analysis 10 times for robustness.

Step 3: Quality Control

Before testing for differences, we check: do my samples look right?

◉

PCA (2D & 3D)

See how your samples cluster. Do biological replicates group together? Do conditions separate? Outliers are easy to spot.

▦

Sample Distance Heatmap

Pairwise similarity between all samples. Replicates should be most similar to each other.

▬

Correlation Heatmap

How well do expression profiles correlate? Helps identify batch effects or sample swaps.

∿

Density Plots

Expression distribution per sample. All samples should look similar after normalization.

Adaptive: The pipeline automatically adjusts its QC plots based on sample count — skips 3D PCA for tiny experiments, simplifies heatmaps for very large cohorts.

Step 4: Differential Expression

The core question: which genes/proteins change between my conditions?

How it works

  • You define contrasts: e.g., "Treatment vs Control"
  • Statistical models test each gene/protein for significant change
  • Results are filtered by:
    • Fold change — how much did it change?
    • Adjusted p-value — is the change statistically reliable?

Methods used

Data typeMethod
ProteomicsLimma (multi-imputation consensus)
RNA-seqDESeq2 or Limma-voom

What you get

  • Volcano plots — visualize effect size vs significance for each contrast
  • MA plots — mean expression vs fold change
  • Heatmaps of top differentially expressed features
  • Tabular results with log2 fold-change, p-values, and gene annotations
Proteomics bonus: Multi-imputation consensus means a protein is only called significant if it passes in most of the 10 imputation rounds — reducing false positives from imputation noise.

Step 5: Clustering — finding patterns

Group genes/proteins that behave similarly across your conditions.

☵

Hierarchical

Builds a tree (dendrogram) showing which features are most similar. Cut the tree to get clusters.


Best for: exploring overall structure

◔

Partition (k-means)

Splits features into k groups that minimize within-group variance. Auto-picks the best k.


Best for: clean, distinct clusters

☷

Binary Patterns

Assigns features to up/down patterns across conditions (e.g., "up in A, down in B and C").


Best for: condition-specific responses

Binary Patterns explained: With 3 conditions, a protein with pattern 1-0-0 is high in condition A but low in B and C. The pipeline finds all such patterns and groups proteins accordingly — great for identifying condition-specific biology.

Binary Patterns: a closer look

Each gene/protein is matched to a response pattern across your experimental groups:

Ctrl DrugA DrugB
0 1 0 "Responds only to Drug A"
0 0 1 "Responds only to Drug B"
0 1 1 "Responds to both drugs"
1 0 0 "High only in control (down with both)"

Why this is useful

  • Immediately tells you which proteins/genes respond to which treatment
  • Finds shared responses across conditions (common pathways)
  • Finds condition-specific responses (unique biology)
  • Each pattern group can be sent to pathway enrichment for biological interpretation

How assignment works

Each gene's expression profile is correlated with every possible pattern. It gets assigned to the best-matching pattern (Pearson correlation ≥ 0.8). Unmatched genes are left unassigned.

How do you use it?

1 Prepare your config

A YAML file describing your experiment: where the data lives, what your conditions are, which contrasts to test.

modes:
  proteomics:
    engine: "DIANN"
    effects:
      color: "Treatment"
      samples: "SampleID"
    de:
      p_cutoff: 0.05
      linear_fc_cutoff: 1.5

2 Run the pipeline

A single command runs everything:

targets::tar_make()

3 Collect outputs

Find plots, tables, and Excel files organized by analysis step in your output directory.

4 Iterate

Change a parameter in the config, re-run — only affected steps recompute.
