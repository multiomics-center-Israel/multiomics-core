Important during R installation: Make sure the checkbox "Save version number in registry" is checked (it is by default). This allows Rscript to be found from the command line.

Install R first, then RTools. Use all default settings — just click Next through both installers.

2
Get the Pipeline Code
manual ~5 min

Step 2a — Install Git for Windows

Git is needed to download the pipeline code. No account or login required — just install it.

📥 Download Git for Windows git-scm.com — click the downloaded file and use all default settings
During installation: Just click Next on every screen — all the defaults are fine. No GitHub account is needed. After installing, close and re-open Command Prompt so it picks up the new git command.

Step 2b — Download the pipeline

Open Command Prompt (press Win + R, type cmd, press Enter).

Where do you want to install the pipeline?

Type the folder path below — the command will update automatically.

Copy and paste these two lines into Command Prompt:

cd /d C:\Users\Lab\Documents
git clone --branch Dor_branch https://github.com/multiomics-center-Israel/multiomics-core.git multiomics-core
This creates the folder C:\Users\Lab\Documents\multiomics-core. No login or password will be asked — the repository is public.
Alternative (no git needed): Dor can also copy the multiomics-core folder to this computer via USB drive or network share. If so, skip straight to Step 3.
Already have the pipeline? Just pull the latest version.

First, close the wizard if it’s running — the pipeline locks run.R so git can’t overwrite it. Close the black Command Prompt window that hosts the wizard, or run this in a new Command Prompt:

taskkill /F /IM Rscript.exe /T
taskkill /F /IM Rterm.exe /T
taskkill /F /IM R.exe /T

Then pull the latest code:

cd /d C:\path\to\multiomics-core
git pull origin Dor_branch

This updates the code in-place — no need to re-run install.bat unless the release notes mention new R packages. Then relaunch the wizard.

3
Run the Installer
automated ~15 min (first time)

Open the multiomics-core folder and double-click:

📄
install.bat
Installs R packages + configures wizard + creates desktop shortcut

This will:

  • Verify R is installed correctly
  • Install all 398 required R packages (automated, takes ~15 min first time, seconds on re-run)
  • Download and install pandoc (the tool that renders the HTML report) if it's not already on the machine — ~30 seconds, silent
  • Ask to configure wizard defaults (which analysis modes, default settings, theme)
  • Create a "Multiomics Pipeline" shortcut on your desktop
Be patient: The first-time package install downloads and compiles ~400 packages. You'll see lots of text scrolling — this is normal. Don't close the window until it says "Setup complete!"
Re-running is safe: If you run install.bat again later, it skips already-installed packages (takes seconds) and preserves your configuration.
After it finishes: You'll have a desktop icon called "Multiomics Pipeline". Double-click it any time to launch the wizard in your browser. That's it!

✅ Setup Complete

Double-click the "Multiomics Pipeline" icon on your desktop to start.

The wizard will open in your browser. Upload your data files, configure the analysis, and click Run.

For help or issues, contact: bioinfo.multiomics@technion.ac.il

Troubleshooting
"Rscript is not recognized" error
R was not added to the system PATH during installation. Fix:
1. Open Start Menu → search "Environment Variables"
2. Click "Edit the system environment variables"
3. Click "Environment Variables" button
4. Under System variables, find Path, click Edit
5. Add: C:\Program Files\R\R-4.5.2\bin (adjust version number if different)
6. Click OK everywhere, then restart Command Prompt and try again
Package installation fails with compilation errors
This usually means RTools is not installed or not found. Check:
1. Make sure RTools 4.5 is installed (not an older version)
2. Open R and run: Sys.which("make") — it should return a path
3. If empty, reinstall RTools and restart your computer
4. Run install.bat again
The wizard opens but nothing happens when I click "Run"
The "Run Pipeline" button requires the backend server (started by launch_wizard.bat). If you opened the HTML file directly in a browser, the Save/Run buttons won't work — always launch via the desktop shortcut or launch_wizard.bat.
How do I update the pipeline later?
Open Command Prompt, navigate to the pipeline folder, and run:
cd %USERPROFILE%\Documents\multiomics-core
git pull
install.bat

This pulls the latest code and installs any new packages (skips what's already installed). Your wizard configuration is preserved across updates.
Can I move the folder after installation?
Yes, but you'll need to re-run install.bat to update the desktop shortcut to point to the new location. The R packages are stored inside the project folder (in renv/library), so they move with it.
How do I change the wizard defaults (available modes, theme, etc.)?
Double-click configure_wizard.bat in the pipeline folder. It lets you choose which analysis modes are visible, set default values for all fields, pick the theme, and more. Changes take effect on the next wizard launch.
